# UoC AI Decision Hub

A lightweight, interactive decision guide for students and instructors.

## Publish with GitHub Pages (free)

1. Sign in or create an account at https://github.com.
2. Create a **New repository** named `uoc-ai-decision-hub`.
3. Choose **Public** if you want the GitHub Pages site to be freely accessible.
   Do not upload confidential UoC information or student data.
4. On the new repository page, choose **Add file → Upload files**.
5. Upload `index.html` and `.nojekyll` from this folder.
6. Commit the files to the `main` branch.
7. Open **Settings → Pages** in the repository.
8. Under **Build and deployment**, select **Deploy from a branch**.
9. Choose branch **main** and folder **/(root)**, then click **Save**.
10. Wait a few minutes and refresh the Pages settings. GitHub will show the published URL.
    It will usually look like:
    `https://YOUR-GITHUB-USERNAME.github.io/uoc-ai-decision-hub/`

## Test the published site

- Open the published URL on a phone and a desktop.
- Try both Student and Instructor pathways.
- Check one-question-at-a-time navigation, back/next, results, restart, and print/copy.
- Share the URL with a small test group before wider distribution.

## Updating the site

Edit `index.html` in the repository, commit the change, and GitHub Pages will publish the update.

## Important notes

- GitHub Pages is static hosting. This tool currently works as a standalone client-side HTML page and does not require a server.
- A public GitHub repository means the source code is publicly viewable. The published website is also public.
- GitHub Pages is not an access-control system for restricting the site to UoC accounts.
- Check UoC policy and obtain any required institutional approval before publishing under the UoC name or distributing it institution-wide.
- GitHub Pages documentation: https://docs.github.com/en/pages/getting-started-with-github-pages
